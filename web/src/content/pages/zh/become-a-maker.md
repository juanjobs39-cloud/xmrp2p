**简短回答：** 做市方持有 XMR，并以高于参考价的差价换取 USDT。你可以**在浏览器中进行，无需安装任何东西**（打开的标签页就是你的服务器），也可以**用自己的服务器或电脑 24/7 运行**。两种方式都没有人托管你的资金。平台在 Arbitrum One 上使用真实资金运行（每笔兑换最多 100 USDT），另有测试网练习模式。

## 成为做市方的两种方式

| | 在浏览器中（推荐） | 自己的 24/7 服务器 |
|---|---|---|
| 适合 | 所有人 | 有技术基础的做市方 |
| 配置 | 无需配置：打开[做市方页面](/zh/maker/) | Python、`monero-wallet-rpc` 和做市程序（[指南](https://github.com/juanjobs39-cloud/xmrp2p/blob/main/maker/README.md)） |
| 何时提供报价 | 电脑上的标签页打开期间 | 全天候 |
| 你的密钥 | 在浏览器中，用你的密码加密，并保存在备份里 | 在你的服务器上 |
| USDT 收款 | 直接到你的 MetaMask | 到你配置的地址 |

**从这里开始：**[在浏览器中成为做市方 →](/zh/maker/)

## 浏览器方式需要什么

| 条件 | 说明 |
|---|---|
| 一台保持标签页打开的电脑 | 手机会让标签页休眠 |
| 用于提供的 XMR | 发送到页面给出的地址；10 个确认后解锁 |
| 少量用作 Gas 的 ETH | 用于领取；可从 MetaMask 一键充值 |
| 密码和备份文件 | 没有备份，就无法在其他浏览器中恢复做市方 |

## 价格如何确定

程序取多个公开数据源（Kraken、CoinGecko 和 KuCoin）的中位数，如果某个数据源偏离中位数太多就放弃该报价，然后加上你的差价。你可以设置：

- 相对参考价的差价，
- 每笔兑换的最低和最高金额，
- 最大敞口（同时占用的 XMR），
- 同时进行的兑换数量。

## 安全规则（浏览器和服务器）

- 没有有效的链上存入时，绝不发送 XMR。
- 没有锁定 XMR 时，绝不领取。
- 不在 t1 之前的最后几分钟尝试领取。
- 每笔交易发送前都会先模拟。
- 如果买方退款，会自动取回 XMR。

## 做市方的风险

- **波动：** 从报价到领取之间，价格可能变化。
- **在线：** 如果你在 t0 和 t1 之间关闭了标签页（或服务器宕机），你将拿不到款；买方会退款，你需要回来取回 XMR。
- **备份：** 备份文件（或程序的数据库）保存着每笔兑换的半把密钥；没有它就无法取回 XMR。
- **监管：** 做市在你的国家可能有法律影响。开始前请先确认。

以上都不保证盈利。完整的安装指南见 [maker/README.md](https://github.com/juanjobs39-cloud/xmrp2p/blob/main/maker/README.md)。
