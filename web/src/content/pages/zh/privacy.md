**简短回答：** 我们没有账户，不使用 Cookie 或分析工具，也不存储你的密钥。有些数据天然公开（USDT 链上的交易），我们的服务器只处理运行所需的最少技术数据。例外是通过 Trocador 的即时兑换，详见下文。

## 我们不收集的内容

- 姓名、邮箱、电话或身份证件。
- 追踪 Cookie 或第三方分析。
- 私钥、助记词或恢复文件的内容。

## 我们的服务器处理的内容（Cloudflare）

| 数据 | 用途 | 保存期限 |
|---|---|---|
| IP 地址 | 防滥用限制和按地区屏蔽 | MoneroP2P 兑换中不存储；Cloudflare 可能依其政策记录 |
| 公开的协议消息（公钥、DLEQ 证明、查看密钥） | 让你和做市方完成兑换 | 房间在 3 天后自动删除 |
| 做市方报价 | 显示报价簿 | 报价有效期间 |

## 通过 Trocador 的即时兑换

当没有 MoneroP2P 做市方能满足你的金额时，应用可以通过 [Trocador](https://trocador.app) 显示即时兑换平台的报价。这个选项的运作方式不同：

- 兑换由你选择的平台完成，而不是 MoneroP2P，你需要把 USDT 发送到该平台的地址。这是托管式服务，有自己的条款和 KYC 评级。
- 我们的服务器替你获取报价并创建兑换。Trocador 上列出的兑换平台要求：当你**创建**兑换时，我们须保存与兑换 ID 关联的你的 **IP 地址、浏览器语言以及浏览器或设备信息（user agent）**，以便回应 Trocador 转给我们的执法机构请求。
- 按照 Trocador 的建议，我们会**无限期**保存这些数据，因为此类请求可能在兑换很久之后才到达。这些数据不会用于任何其他目的，除非回应此类请求，否则不会与任何人共享。
- 仅查看报价不会保存任何数据。与 MoneroP2P 做市方的兑换从不保存这些数据。
- 如果想避免，请使用 MoneroP2P 做市方，或直接访问 Trocador（届时由它按自己的条款保存你的数据）。Tor 或 VPN 可以减少 IP 暴露的信息。

## 链上公开的内容

- 你的 USDT 存入、EVM 钱包地址和合约事件在 USDT 网络上是公开的。
- 门罗币交易在设计上是私密的，但兑换的共享查看密钥让双方都能看到共享地址。

## 门罗币节点代理

如果你使用我们的代理，它能看到你的浏览器发出了哪些查询（例如你核验的是哪笔交易）。如果想避免，请使用自己的节点。

## 浏览器存储

应用会在你的浏览器中保存一份进行中兑换的**加密**副本，密码与恢复文件相同。清除本站数据即可删除。

## MoneroP2P Wallet 扩展

该扩展**不收集也不发送任何个人数据**：没有账户、统计分析或遥测。你的助记词、密钥和交易记录**只在你的浏览器中加密保存**（Argon2id 和 XChaCha20-Poly1305），从不外传。同步时，扩展会连接你选择的门罗币节点（默认是上文所述的我们的代理）；该节点能看到区块链查询和你发送的已签名交易，但看不到你的密钥。卸载扩展会删除其全部数据。

对于 Arbitrum 账户，扩展会查询 Arbitrum 的公共 RPC（arb1.arbitrum.io；测试时为 sepolia-rollup.arbitrum.io），它能看到你的 Arbitrum 公开地址和已签名的交易，但看不到你的密钥。在 monerop2p.app 和 fiat.monerop2p.app 上，只有在你批准后才会把你的账户或门罗币地址提供给网站，你也可以在设置中断开连接。

**兑换(可选)。** 如果你使用扩展中的“兑换”标签页,报价和兑换会通过我们的 API(api.monerop2p.app)向 Trocador 请求。规则与应用中通过 Trocador 的兑换相同:创建兑换时,应这些交易所的要求,我们会保存与该兑换 ID 关联的 IP、语言和浏览器信息。你的兑换列表以加密形式保存在浏览器中。如果你不使用“兑换”,扩展不会连接我们的 API。

## P2P Fiat 通知(可选)

如果你在 fiat.monerop2p.app 开启通知,我们会保存浏览器提供的订阅地址,并与你的 P2P 账户关联,以便在应用关闭时告诉你有新的请求或订单变化。通知经过你浏览器的推送服务(Google、Mozilla、Apple 或 Microsoft),内容为空:不包含金额、昵称或订单信息,文字由网站显示。你可以随时关闭,订阅会被删除。如果不开启,我们不会保存任何内容。

你也可以在"账户"中连接 P2P Fiat 的 Telegram 机器人。我们只保存你与机器人的聊天 ID 和语言,并与你的 P2P 账户关联。消息只说明通知类型(例如"新请求"或"买家已标记付款")并附上订单链接:绝不包含金额、昵称或付款信息。Telegram 作为消息服务,能看到你在使用机器人以及这些消息。如果你用"接受"或"拒绝"按钮回复请求,机器人会像网页一样记录。向机器人发送 /stop,或在应用中点"断开 Telegram",即可删除关联;屏蔽机器人也会删除。 机器人的按钮会在 Telegram 内打开应用。这样打开时,Telegram 会向页面传递你的部分 Telegram 账户信息(如名字);应用启动时会删除这些信息,绝不发送到我们的服务器。你的 P2P 账户、密钥和托管签名都留在你的设备上,与浏览器中一样。 新广告提醒(机器人中的 /alerts)无需账户即可使用:我们只保存 chat_id、语言和你选择的筛选条件(买入或卖出、币种),「Turn alerts off」或 /stop 即可删除。提醒只包含市场上本已公开的信息。 如果你从机器人打开兑换(/swap),我们会随兑换保存一个代码,用来在该聊天中通知进度(只有状态,没有金额或地址);它会随兑换一起删除。
