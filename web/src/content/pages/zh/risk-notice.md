**简短回答：** 加密货币波动大，交易无法撤销，USDT 发行方可以冻结地址，而且本软件尚未经过外部审计（每笔兑换上限为 100 USDT）。只有在你理解并接受这些风险时才使用，切勿投入你承受不起损失的资金。

## 主要风险

| 风险 | 对你意味着什么 |
|---|---|
| **价格波动** | 兑换进行期间，XMR 和 USDT 的价格可能变化。 |
| **不可撤销** | 已确认的交易无法撤销。地址填错是永久性的。 |
| **USDT 冻结** | Tether 可以冻结地址。如果冻结了你的地址或合约，资金可能被卡住。 |
| **尚无外部审计** | 合约已通过自动化验证（Halmos、Aderyn、Slither），但没有外部审计，可能存在导致损失的缺陷。每笔兑换上限为 100 USDT。 |
| **合约期限** | 如果 XMR 未到账而你没有在 t0 之前退款，做市方可能领走你的 USDT。 |
| **恢复文件** | 如果它和浏览器一起丢失，进行中兑换的资金将无法找回。 |
| **交易对手** | 做市方是独立的。合约会保护你，但前提是你及时行动。 |
| **网络和节点** | 拥堵、节点故障或高手续费可能延误你的操作。 |
| **法律与税务** | 你需自行遵守所在国家的法律。部分司法辖区限制此类操作。 |

## 我们不做的事

- 不提供财务、法律或税务建议。
- 不承诺收益或汇率。
- 不保管资金，也无法撤销操作。
