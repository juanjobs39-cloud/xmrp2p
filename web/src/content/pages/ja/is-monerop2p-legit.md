**短い答え：** MoneroP2Pはオープンソースの非カストディ型プラットフォームで、2026年10月26日から実際の資金で稼働しています。私たちの言葉を信じる必要はありません。以下の主張はすべて公開情報で確認できます。一方で、まだ新しいプロジェクトで外部監査を受けていないため、上限は意図的に低くしています。

## 自分で確認できること

| 主張 | 確認方法 |
|---|---|
| アトミックスワップでは誰もあなたのUSDTを預からない | コントラクトには管理者・一時停止・アップグレードの機能がありません。[Sourcify](https://repo.sourcify.dev/42161/0x88fc05Cb07C5b69fbed1F7B1c1F784Cd26e99535)（完全一致）または[Arbiscan](https://arbiscan.io/address/0x88fc05Cb07C5b69fbed1F7B1c1F784Cd26e99535)で検証済みのソースを読めます。 |
| コントラクトは検査済み | Halmosは7つの性質すべてを証明し、Aderynは高リスクの問題を0件、Slitherは中・高リスクの問題を検出しませんでした。[レポート](https://github.com/juanjobs39-cloud/xmrp2p/blob/main/docs/AUDITORIA-GRATUITA.md)と[公開されている実行結果](https://github.com/juanjobs39-cloud/xmrp2p/actions/workflows/auditoria.yml)をご覧ください。 |
| 上限と手数料は引き上げられない | 1回あたり最大100 USDTと手数料上限1%はコントラクトの定数です。現在の手数料は0.5%で、メイカーが支払います。 |
| サイトは公開されたコードで動いている | すべてのコードは[GitHub](https://github.com/juanjobs39-cloud/xmrp2p)でAGPL-3.0のもと公開されています。各リリースで[SHA256SUMS](/SHA256SUMS)を公開しているため、読み込んだファイルを自分のビルドと比較できます。 |
| P2P Fiatは単独でXMRを動かせない | 各注文はMoneroの2-of-3マルチシグを使います。買い手・売り手・仲裁者が鍵を1つずつ持ち、2つが必要です。[P2P Fiatの仕組み](https://fiat.monerop2p.app/en/how-it-works/)をご覧ください。 |
| 鍵はあなたの手元にある | 鍵はブラウザ内で生成されます。スワップアプリにアカウントはなく、アプリのページは厳格なコンテンツセキュリティポリシーを適用しており、ページのソースで確認できます。 |
| 実際の資金で動作した | メインネットでの最初のスワップは2026年10月26日に完了しました。各スワップはファクトリーを通じて専用のコントラクトを作成し、Arbiscanで確認できます。 |

## 限界と、まだないもの

- **外部監査がない。** 上記の検査は自動ツールによるもので、監査会社によるレビューではありません。そのためコントラクトは1回のスワップを100 USDTに制限しています。
- **新しいプロジェクト。** 2026年10月に公開されました。取引量は少なく、P2P Fiatでは通貨によって広告がわずかです。
- **即時交換はカストディ型。** BTCやETHなどからの交換はTrocador経由で第三者の交換所を使います。選んだ交換所が数分間コインを預かり、見積もりにはMoneroP2Pの1%のマージンが含まれます。
- **P2P Fiatが守るのはXMRで、銀行送金ではない。** 法定通貨の支払いはプラットフォームの外で行われます。PayPalやカードなど取り消し可能な方法はリスクが高く、紛争は私たちが運営する仲裁者が判断します。
- **鍵の管理はあなたの責任。** リカバリーファイルやアカウントのパスワードを失くした場合、私たちは復元できません。
- **会社による保証はない。** 預金保険もサポート窓口もありません。[リスクに関する注意](/ja/risk-notice/)をお読みください。

## 運営者と連絡方法

MoneroP2Pは独立したオープンソースプロジェクトです。プロトコルはAthanorLabsのアトミックスワップに基づいています。[お問い合わせページ](/ja/contact/)から連絡でき、脆弱性はリポジトリのSecurityタブから非公開で報告できます。シードフレーズやリカバリーファイル、スワップの「ロック解除」のための支払いを求めることは決してありません。

## 使う前に

1. テスト資金で練習モードを試す：[スワップアプリ](/ja/app/)のURLに `?red=prueba` を追加します。
2. 少額から始める。
3. [仕組み](/ja/how-it-works/)と[セキュリティのページ](/ja/security/)を読む。
4. 頼まれても、プラットフォームの外で取引しない。
