**要点：** 暗号資産は価格変動が大きく、取引は取り消せず、USDTの発行元はアドレスを凍結でき、このソフトウェアはまだ外部監査を受けていません（1回のスワップは100 USDTが上限）。これらのリスクを理解し受け入れられる場合にだけ使い、失って困るお金では決して使わないでください。

## 主なリスク

| リスク | あなたにとっての意味 |
|---|---|
| **価格変動** | スワップの進行中に、XMRやUSDTの価格が変わることがあります。 |
| **取り消し不可** | 承認された取引は元に戻せません。アドレスの間違いは取り返しがつきません。 |
| **USDTの凍結** | Tetherはアドレスを凍結できます。あなたのアドレスやコントラクトが凍結されると、資金が動かせなくなることがあります。 |
| **外部監査がまだ** | コントラクトは自動検証（Halmos、Aderyn、Slither）を通過していますが、外部監査はなく、損失につながる不具合がある可能性があります。1回のスワップは100 USDTが上限です。 |
| **コントラクトの期限** | XMRが届かなかったのにt0までに返金しないと、メイカーがあなたのUSDTを受け取れてしまう可能性があります。 |
| **復元ファイル** | ブラウザと一緒に失うと、進行中のスワップの資金を取り戻せません。 |
| **取引相手** | メイカーは独立した存在です。コントラクトはあなたを守りますが、それはあなたが期限内に行動した場合に限ります。 |
| **ネットワークとノード** | 混雑、ノードの障害、高い手数料により、操作が遅れることがあります。 |
| **法律と税金** | お住まいの国の法律を守る責任はあなたにあります。こうした取引を制限している国・地域もあります。 |

## 私たちがしないこと

- 金融・法律・税務の助言は行いません。
- 利益やレートは約束しません。
- 資金を預からず、操作を取り消すこともできません。
