**MoneroP2P Wallet**은 브라우저 확장 프로그램으로 작동하는 모네로(XMR) 지갑입니다. 키는 기기에서 만들어지고 비밀번호로 암호화되어 기기에 남습니다. 같은 지갑에서 MoneroP2P 서비스를 통해 USDT나 현지 통화로 XMR을 살 수 있습니다.

## 할 수 있는 일

- 모네로 표준 25단어 시드로 지갑 **생성 또는 복구**.
- 결제마다 새 서브주소와 QR 코드로 **받기**. 아무도 결제를 서로 연결할 수 없습니다.
- 확인 전에 정확한 수수료와 받는 사람 요약을 보고 **보내기**.
- **탐색:** [USDT→XMR 교환](/ko/app/)(주소 자동 입력)과 [P2P Fiat](https://fiat.monerop2p.app/en/app/)를 한 번에 열어 계좌이체, 현금 등으로 구매.

## 보호 방식

| 보호 | 기능 |
|---|---|
| 비수탁 | 시드는 기기 밖으로 나가지 않으며, 본인 외에는 아무도 XMR을 옮길 수 없습니다. |
| 강력한 암호화 | 비밀번호를 Argon2id(64 MiB)로 키로 바꾸고 XChaCha20-Poly1305로 지갑을 암호화합니다. |
| 자동 잠금 | 15분 동안 사용하지 않거나(변경 가능) 브라우저를 닫으면 자동으로 잠깁니다. |
| 원격 코드 없음 | 모든 코드가 확장 프로그램 안에 있으며 엄격한 보안 정책(CSP)을 적용합니다. |
| 주소 오염 방지 | 이전에 쓴 주소와 비슷하지만 다른 주소를 붙여 넣으면 경고합니다. |
| 검증 가능 | 패키지는 재현 가능한 빌드로 만들어져 누구나 소스 코드와 일치하는지 확인할 수 있습니다. |

## 시작하기 전에

1. 시드를 **종이에** 적어 안전하게 보관하세요. 돈을 되찾는 유일한 방법입니다.
2. 확장 프로그램에는 길고 고유한 비밀번호를 쓰세요.
3. 먼저 소액으로 시험해 보세요.
