**简短回答：** 代价最高的错误是：选错网络、漏填交易所要求的 memo 或 tag、发送金额低于最低限额、Gas 不足，以及复制了假地址。签名前请核对网络、完整地址和金额：交易无法撤销。

## 错误 1：选错网络

同一种代币存在于多个网络上（例如 Tron、以太坊和 Arbitrum 上的 USDT）。如果你通过收款方不支持的网络发送，资金可能丢失，或需要代价高昂的找回。

**如何避免：** 与收款方确认网络。MoneroP2P 应用只显示已启用的网络。

## 错误 2：漏填 memo、tag 或 payment ID

有些交易所让许多客户共用一个地址，通过 memo 或 tag 识别你。漏填的话，存入可能无法入账。

**如何避免：** 如果交易所显示了 memo 或 tag，一定要填写。在门罗币上，交易所通常会给你专属的子地址，不需要 payment ID。

## 错误 3：低于最低金额

交易所和服务都有最低存入金额。低于这个金额，存入可能不会入账。在 MoneroP2P 上，每个报价都标明了最低和最高金额。

## 错误 4：Gas 不足

转移 USDT 需要该网络的原生币（ETH、TRX…）。没有它，你既不能存入也不能退款。

**如何避免：** 兑换前至少准备好 3 笔交易的费用（存入、确认和可能的退款）。

## 错误 5：投毒地址和剪贴板恶意软件

攻击者会从与你地址相似的地址发送极小金额，诱使你从历史记录中复制。有些恶意软件会替换你复制的地址。

**如何避免：** 从源头复制地址（不要从历史记录复制），并完整核对开头**和**结尾。

## 错误 6：无限授权

有些应用会请求无限额度地花费你的代币。如果该应用被攻破，它可能会掏空你的余额。

**如何避免：** 只授权所需金额。MoneroP2P 只授权兑换的确切金额。

## 错误 7：轻信主动联系你的「客服」

任何正规机构都不会向你索要助记词、恢复文件或用于「解锁」的资金。
