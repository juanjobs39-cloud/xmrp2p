**简短回答：** 门罗币（XMR）是一种默认隐藏谁发送、谁接收以及金额多少的加密货币。相比之下，比特币的每个地址和金额都是公开的，任何人都可以追踪资金。门罗币自 2014 年起存在，并且是开源的。

## 主要区别

| | 门罗币（XMR） | 比特币（BTC） |
|---|---|---|
| 发送方 | 隐藏（环签名） | 公开 |
| 接收方 | 隐藏（一次性地址） | 公开 |
| 金额 | 隐藏（RingCT） | 公开 |
| 隐私 | 始终开启 | 可选且有限 |
| 出块时间 | 约 2 分钟 | 约 10 分钟 |
| 发行 | 自 2022 年起有少量永久尾部发行 | 上限 2100 万 |
| 智能合约 | 没有 | 有限的脚本 |

## 它如何实现隐私

- **环签名：** 你的交易会与链上的其他输出混合，因此无法知道哪一个是真的。
- **隐身地址：** 每笔付款都发往一个一次性地址；你的公开地址从不出现在链上。
- **RingCT：** 金额是加密的，但网络仍能验证没有凭空造币。

## 可替代性

由于历史记录不可见，每个 XMR 都可以与其他任何 XMR 互换。而透明的币可能因为历史记录而被拒收。

## 查看密钥

门罗币允许你分享**查看密钥**，它能显示收到的付款，但不能花费。MoneroP2P 用它让买方核验 XMR 是否已到达共享地址。

## 需要注意的事

- 一些中心化交易所已在部分司法辖区下架门罗币。因此，像原子交换这样无需中介的方式变得更加重要。
- 隐私并不能免除你遵守所在国家法律的义务。
