**Коротко:** скачайте кошелёк Monero с официального сайта, создайте новый кошелёк, запишите сид на бумаге и скопируйте адрес в разделе «Получить». Для режима практики MoneroP2P нужен кошелёк **stagenet** (тестовая сеть Monero), который можно выбрать в некоторых настольных кошельках.

## Известные варианты

| Кошелёк | Платформа | Примечания |
|---|---|---|
| Monero GUI и CLI (официальные) | Windows, macOS, Linux | От проекта Monero; поддерживают stagenet |
| Feather Wallet | Windows, macOS, Linux | Лёгкий настольный кошелёк; поддерживает stagenet |
| Cake Wallet | Android, iOS, компьютер | Популярен на телефонах |
| Другие | Разные | Актуальный список — на getmonero.org |

> Всегда скачивайте с официального сайта кошелька и проверяйте подписи, если проект их публикует. Остерегайтесь приложений-подделок в магазинах.

## Пошагово

1. **Установите кошелёк** с официального сайта.
2. **Создайте новый кошелёк.** Он попросит пароль: пароль защищает файл на этом устройстве, это не ваш сид.
3. **Сохраните сид.** Это список слов (25 в классическом формате, 16 в формате Polyseed, который используют некоторые кошельки). Запишите их на бумаге по порядку. Кто знает эти слова, тот управляет вашими средствами.
4. **Запишите высоту восстановления**, если кошелёк её показывает: она ускоряет восстановление.
5. **Скопируйте адрес** в разделе «Получить». Основные адреса Monero в реальной сети начинаются с `4`, субадреса — с `8`. В stagenet они начинаются с `5` или `7`.

## Для режима практики MoneroP2P (stagenet)

- В Monero GUI или Feather выберите **stagenet** при создании кошелька (в настройках или при запуске).
- XMR в stagenet ничего не стоят; их можно получить из краников stagenet.
- В режиме практики приложение MoneroP2P принимает только адреса stagenet.

## Хорошие привычки

- Никогда никому не сообщайте сид, даже поддержке.
- Для большей приватности используйте новый адрес или субадрес для каждого свопа.
- При получении XMR сеть требует около 10 подтверждений (примерно 20 минут), прежде чем их можно потратить.
