**Коротко:** завантажте гаманець Monero з офіційного сайту, створіть новий гаманець, запишіть сід на папері й скопіюйте адресу в розділі «Отримати». Для режиму практики MoneroP2P потрібен гаманець **stagenet** (тестова мережа Monero), який можна обрати в деяких настільних гаманцях.

## Відомі варіанти

| Гаманець | Платформа | Примітки |
|---|---|---|
| Monero GUI і CLI (офіційні) | Windows, macOS, Linux | Від проєкту Monero; підтримують stagenet |
| Feather Wallet | Windows, macOS, Linux | Легкий настільний гаманець; підтримує stagenet |
| Cake Wallet | Android, iOS, комп’ютер | Популярний на телефонах |
| Інші | Різні | Актуальний список — на getmonero.org |

> Завжди завантажуйте з офіційного сайту гаманця й перевіряйте підписи, якщо проєкт їх публікує. Остерігайтеся застосунків-підробок у магазинах.

## Покроково

1. **Встановіть гаманець** з офіційного сайту.
2. **Створіть новий гаманець.** Він попросить пароль: пароль захищає файл на цьому пристрої, це не ваш сід.
3. **Збережіть сід.** Це список слів (25 у класичному форматі, 16 у форматі Polyseed, який використовують деякі гаманці). Запишіть їх на папері по порядку. Хто знає ці слова, той керує вашими коштами.
4. **Запишіть висоту відновлення**, якщо гаманець її показує: вона пришвидшує відновлення.
5. **Скопіюйте адресу** в розділі «Отримати». Основні адреси Monero в реальній мережі починаються з `4`, субадреси — з `8`. У stagenet вони починаються з `5` або `7`.

## Для режиму практики MoneroP2P (stagenet)

- У Monero GUI або Feather оберіть **stagenet** під час створення гаманця (у налаштуваннях або під час запуску).
- XMR у stagenet нічого не варті; їх можна отримати з кранів stagenet.
- У режимі практики застосунок MoneroP2P приймає лише адреси stagenet.

## Добрі звички

- Ніколи нікому не повідомляйте сід, навіть підтримці.
- Для більшої приватності використовуйте нову адресу чи субадресу для кожного свопу.
- Під час отримання XMR мережа вимагає близько 10 підтверджень (приблизно 20 хвилин), перш ніж їх можна витратити.
