**要点：** Monero（XMR）は、誰が送り、誰が受け取り、いくらなのかをデフォルトで隠す暗号資産です。一方ビットコインでは、すべてのアドレスと金額が公開され、誰でも資金を追跡できます。Moneroは2014年から存在し、オープンソースです。

## 主な違い

| | Monero（XMR） | ビットコイン（BTC） |
|---|---|---|
| 送信者 | 隠される（リング署名） | 公開 |
| 受信者 | 隠される（使い捨てアドレス） | 公開 |
| 金額 | 隠される（RingCT） | 公開 |
| プライバシー | 常に有効 | 任意で限定的 |
| ブロック時間 | 約2分 | 約10分 |
| 発行 | 2022年から少量の恒久的なテールエミッション | 上限2100万 |
| スマートコントラクト | なし | 限定的なスクリプト |

## プライバシーの実現方法

- **リング署名：** あなたの取引はチェーン上のほかの出力と混ぜられ、どれが本物か分からなくなります。
- **ステルスアドレス：** 支払いはそれぞれ使い捨てのアドレスに送られ、あなたの公開アドレスがチェーン上に現れることはありません。
- **RingCT：** 金額は暗号化されていますが、それでもネットワークはお金が無から作られていないことを検証します。

## 代替可能性

履歴が見えないため、どのXMRもほかのXMRと交換可能です。透明なコインでは、履歴を理由に一部の単位が受け取りを拒まれることがあります。

## 閲覧鍵

Moneroでは**閲覧鍵**を共有できます。受け取った支払いは見えますが、使うことはできません。MoneroP2Pはこれを使って、買い手がXMRが共有アドレスに届いたことを確認できるようにしています。

## 知っておきたいこと

- 一部の中央集権型取引所は、特定の国・地域でMoneroを上場廃止しています。だからこそ、アトミックスワップのような仲介者のない方法が重要です。
- プライバシーがあっても、お住まいの国の法律を守る義務はなくなりません。
